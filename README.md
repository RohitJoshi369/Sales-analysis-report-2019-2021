📊 Sales Analysis Dashboard (2019–2021)

📌 Overview

This project is an interactive sales analysis dashboard built to explore and visualize eBay sales data from 2019 to 2021.
It provides key business insights such as sales performance, profit trends, regional distribution, and product category analysis.

🚀 Key Features

📈 Sales Performance Tracking

Total Profit: 286.36K

Total Quantity Sold: 38K

Total Discount Given: 1.56K

🧩 Segment Analysis

Consumer, Corporate, and Home Office segmentation

Identifies highest contributing customer groups

🌍 Regional Insights

Sales distribution across West, East, Central, and South regions

📅 Time Series Analysis

Sales trends from 2019 to 2021

Detects seasonality and growth patterns

🗺️ Geographical Visualization

State-wise sales distribution across the United States

🛍️ Product Performance

Sub-category level insights (Phones, Chairs, Storage, etc.)
